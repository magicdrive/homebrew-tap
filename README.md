# Homebrew Tap for Magicdrive Tools

This is the official [Homebrew](https://brew.sh) tap for the command-line tools developed by [magicdrive](https://github.com/magicdrive). It works with Homebrew on macOS and Linux.

The tap is named `magicdrive/tap`; Homebrew maps that name to this repository, `magicdrive/homebrew-tap`.

## Available Formulae

| Formula | Description | Install |
|---|---|---|
| [ark](https://github.com/magicdrive/ark) | Code intelligence MCP server for AI coding agents, with a repository text dump | `brew install magicdrive/tap/ark` |
| [enma](https://github.com/magicdrive/enma) | Yet another event-driven command runner | `brew install magicdrive/tap/enma` |
| [git-parallel](https://github.com/magicdrive/git-parallel) | Run commands in parallel across multiple git repositories | `brew install magicdrive/tap/git-parallel` |
| [goreg](https://github.com/magicdrive/goreg) | Yet another alternate `goimports` tool | `brew install magicdrive/tap/goreg` |
| [hephaestus](https://github.com/magicdrive/hephaestus) | Release automation for CLIs in any language | `brew install magicdrive/tap/hephaestus` |
| [kirke](https://github.com/magicdrive/kirke) | Yet another command-line tool for converting JSON strings into Golang struct definitions | `brew install magicdrive/tap/kirke` |
| [kjak](https://github.com/magicdrive/kjak) | Send one notification to Slack, Discord and e-mail from the command-line | `brew install magicdrive/tap/kjak` |
| [t](https://github.com/magicdrive/t) | Lazy tmux wrapper | `brew install magicdrive/tap/t` |

Each formula installs the latest release of its tool. Once a formula is installed (or trusted), `brew info magicdrive/tap/<formula>` shows the version; see [Trusting This Tap](#trusting-this-tap).

## How to Install

Install a tool by its full name. Homebrew adds the tap automatically:

```bash
brew install magicdrive/tap/enma
```

Or add the tap first, then install:

```bash
brew tap magicdrive/tap
brew install magicdrive/tap/enma
```

The full name (`magicdrive/tap/<formula>`) always selects the formula of this tap, even if another tap has a formula with the same name.

## Trusting This Tap

Homebrew 7.0.11 and later load formulae from third-party taps such as this one only when they are trusted, because loading a formula runs the tap's Ruby code on your machine.

`brew install magicdrive/tap/<formula>` trusts the formula it installs, so installing, upgrading and uninstalling work as shown on this page without extra steps. Only the installed formula is trusted, not the rest of the tap.

Other commands refuse to load a formula that is not trusted yet. For example, running `brew info` after `brew tap magicdrive/tap` but before installing prints:

```text
Error: Refusing to load formula magicdrive/tap/enma from untrusted tap magicdrive/tap.
```

If you want to inspect a formula before installing it, add the tap and trust only that formula:

```bash
brew tap magicdrive/tap
brew trust --formula magicdrive/tap/enma
brew info magicdrive/tap/enma
```

Trusting the whole tap lets Homebrew load every formula in it, including formulae added later. Do this only if you want that:

```bash
brew trust --tap magicdrive/tap
```

Trust only the taps you need; trusting a tap means trusting its maintainer's Ruby code. To list what you trust:

```bash
brew trust --json=v1
```

To stop trusting a formula or the tap:

```bash
brew untrust --formula magicdrive/tap/enma
brew untrust --tap magicdrive/tap
```

`brew untrust --tap` also removes the trust of each formula of the tap, so `brew info` and other commands refuse to load them again until they are trusted.

If your Homebrew does not have the `brew trust` command, it predates these checks: skip this section.

## Usage

See the README of each tool's repository (linked in the table above).

## How to Upgrade

Upgrade everything installed with Homebrew, including the tools of this tap:

```bash
brew update
brew upgrade
```

Or upgrade a single tool:

```bash
brew update
brew upgrade magicdrive/tap/enma
```

## How to Uninstall

Uninstall a tool:

```bash
brew uninstall magicdrive/tap/enma
```

To remove the tap itself, uninstall its tools first; Homebrew refuses to untap while a formula from the tap is installed:

```bash
brew untap magicdrive/tap
```

## How the Formulae Are Updated

The formulae are generated by the release automation of each tool: each release updates its formula with the new download URLs and SHA-256 checksums. Tools released with [Hephaestus](https://github.com/magicdrive/hephaestus) do this through a pull request, which the maintainer reviews and merges. Please do not edit the formula files by hand; report problems in the tool's repository.
